# Payments

The last stage is the money. After the insurer processes a claim, it issues a
payment, and the module lets you see what was paid against which claims.

## What you can see

- Which claims have been **paid**.
- The **amount paid** against each one.
- The payment reference that ties the money back to the claim.

## How it fits

Payment follows naturally from an approved claim:

```
Approved claim  ->  Insurer issues payment  ->  You match it to the claim
```

You don't have to chase each one by hand — the dashboard and the claim lists
show the status so you can see at a glance what's still outstanding.

!!! note
    Payment messages come from the insurer on their own schedule, so a claim can
    be **Approved** for a while before the matching payment appears.
